# Kanban+

เว็บแอปจัดการงานแบบ Kanban board (แนว Trello) สำหรับทำงานกลุ่มในรายวิชา — นักศึกษาวางแผนงานบนบอร์ด
ส่งการ์ดให้อาจารย์ตรวจ อาจารย์ให้คะแนนและอนุมัติ พร้อมระบบแต้ม/เลเวลที่จูงใจให้ส่งงานตรงเวลา
UI เป็นภาษาไทยทั้งหมด

สร้างด้วย **Next.js 16 (App Router + Server Actions)**, **Prisma 7**, **PostgreSQL (Neon)** และ **NextAuth v5**

---

## ฟีเจอร์

### บอร์ด คอลัมน์ การ์ด
- สร้างบอร์ดได้หลายบอร์ด ตั้งชื่อ/สี/คำอธิบายได้ บอร์ดใหม่มี 4 คอลัมน์ให้เลย:
  **สิ่งที่ต้องทำ → กำลังทำ → กำลังตรวจสอบ → เสร็จสิ้น**
- ลากสลับลำดับการ์ดและคอลัมน์ได้ (ทั้งเมาส์และคีย์บอร์ด) แทรกคอลัมน์ทางซ้าย/ขวาของคอลัมน์ไหนก็ได้
- คอลัมน์ **เสร็จสิ้น** อยู่ขวาสุดเสมอ และคอลัมน์ที่ตั้งชื่อว่า Done / Finish / เสร็จสิ้น จะกลายเป็นคอลัมน์เสร็จสิ้นให้เอง
- การ์ดมีรายละเอียด, กำหนดส่ง, ระดับความสำคัญ, ป้ายกำกับ, ผู้รับผิดชอบ, เช็กลิสต์, ความคิดเห็น
  และไฟล์แนบ (อัปโหลดรูป/ไฟล์ หรือแนบลิงก์)
- ฟิลเตอร์การ์ดตามคำค้น / กำหนดส่ง / ผู้รับผิดชอบ / ระดับความสำคัญ
- บันทึกกิจกรรมของบอร์ดอัตโนมัติ (ใครทำอะไร เมื่อไร)

### ทำงานร่วมกัน
- เชิญสมาชิกด้วยอีเมล (ลิงก์เชิญใช้ครั้งเดียว อายุ 7 วัน) หรือเปิด **ลิงก์แชร์** ให้ใครมีลิงก์ก็เข้าได้
- สิทธิ์ในบอร์ด 3 ระดับ: **เจ้าของ** / **แก้ไขได้** / **ดูอย่างเดียว** — เจ้าของเปลี่ยนสิทธิ์หรือเอาสมาชิกออกได้
  สมาชิกออกจากบอร์ดเองได้

### อาจารย์และรายวิชา
- อาจารย์สร้าง **รายวิชา** แล้วได้รหัสเข้าร่วม 6 ตัว นักศึกษากรอกรหัสเพื่อส่งบอร์ดเข้าวิชา
- อาจารย์เห็นเฉพาะบอร์ดในวิชาของตัวเอง ตรวจการ์ดที่อยู่ในคอลัมน์ "กำลังตรวจสอบ" ได้ที่หน้า **ตรวจงาน**:
  ให้คะแนน 0–100 + ความเห็น แล้ว **อนุมัติ** (การ์ดเข้าคอลัมน์เสร็จสิ้น) หรือ **ส่งกลับแก้ไข**
- บอร์ดที่อยู่ในรายวิชา นักศึกษาลากการ์ดเข้าคอลัมน์เสร็จสิ้นเองไม่ได้ ต้องรออาจารย์อนุมัติ
- ดาวน์โหลดคะแนนทั้งวิชาเป็น **CSV** (1 แถวต่อการ์ด เปิดใน Excel แล้วภาษาไทยไม่เพี้ยน)
- นักศึกษาเห็นแจ้งเตือน **ผลตรวจ (n)** บนแถบด้านข้างเมื่ออาจารย์ตรวจงาน

### แอดมิน
- หน้า **จัดการผู้ใช้**: ตั้ง role (นักศึกษา / อาจารย์ / แอดมิน), ระงับบัญชี, ตั้งรหัสผ่านใหม่ให้ผู้ใช้

### ภาพรวมและแรงจูงใจ
- **Dashboard** สรุปงานค้าง / เลยกำหนด / เสร็จแล้ว, กราฟงานที่ทำเสร็จราย 7 วัน, ความคืบหน้ารายเดือน
- **ค้นหาข้ามบอร์ด** และ **ปฏิทินกำหนดส่ง**
- **ระบบแต้ม**: ทำการ์ดเสร็จ +10, ส่งทันกำหนด +5 (ส่งช้าไม่หักแต้ม) มีเลเวลและสตรีควันที่ทำงานติดกัน
  การ์ด 1 ใบให้แต้มแต่ละชนิดได้ครั้งเดียว ลากเข้า-ออกกี่รอบก็ฟาร์มแต้มไม่ได้

## วิธีใช้งาน

### นักศึกษา
1. **สมัครสมาชิก** (ชื่อ, อีเมล, รหัสผ่านอย่างน้อย 8 ตัว) แล้วระบบพาเข้าสู่ระบบให้ทันที
2. กด **สร้างบอร์ดใหม่** ที่แถบด้านซ้าย แล้วกด **เพิ่มการ์ด** ท้ายคอลัมน์เพื่อเพิ่มงาน
3. คลิกการ์ดเพื่อเปิดหน้าต่างรายละเอียด แก้ไขทุกอย่างได้ในนั้น แล้วกด **บันทึก**
4. ถ้าทำงานในรายวิชา: เปิด **ตั้งค่าบอร์ด → รายวิชา** แล้วกรอกรหัสที่อาจารย์ให้มา
5. ทำงานเสร็จให้ลากการ์ดเข้าคอลัมน์ **กำลังตรวจสอบ** (= ส่งงาน) แล้วรออาจารย์ตรวจ
   ผลตรวจจะขึ้นที่การ์ดและที่เมนู **ผลตรวจ**
6. เปลี่ยนรหัสผ่านได้ที่ **บัญชีของฉัน** (กดชื่อตัวเองที่มุมล่างซ้าย)

### อาจารย์
1. ให้แอดมินตั้ง role เป็น **อาจารย์** ก่อน แล้วจะเห็นเมนู **รายวิชา** และ **ตรวจงาน**
2. **รายวิชา → สร้างรายวิชา** แล้วบอกรหัสเข้าร่วมกับนักศึกษา (สุ่มรหัสใหม่ได้ถ้ารหัสหลุด)
3. **ตรวจงาน** แสดงการ์ดที่รอตรวจจากทุกบอร์ดในวิชา กรองตามวิชา/บอร์ดได้
4. หน้ารายวิชามีปุ่ม **ดาวน์โหลดคะแนน (CSV)** และถอนบอร์ดออกจากวิชาได้

### แอดมิน
- เมนู **จัดการผู้ใช้** — แอดมินแก้บัญชีตัวเองไม่ได้ (กันล็อกตัวเองออก) และลดสิทธิ์อาจารย์ที่ยังมีรายวิชาอยู่ไม่ได้
- การตั้งรหัสผ่านใหม่ไม่ทำให้คนที่ล็อกอินค้างอยู่หลุดออก ถ้าต้องตัดการใช้งานทันทีให้ **ระงับบัญชี**

## เทคโนโลยีที่ใช้

| ส่วน | เทคโนโลยี |
|---|---|
| Framework | Next.js 16 (App Router, Server Actions, Turbopack) + React 19 |
| UI | Tailwind CSS 4 — ไม่ใช้ component library เขียนเองทั้งหมด รองรับธีมสว่าง/มืด |
| ฐานข้อมูล | PostgreSQL บน [Neon](https://neon.tech) (serverless) |
| ORM | Prisma 7 + `@prisma/adapter-neon` |
| ระบบล็อกอิน | NextAuth v5 (Credentials + JWT session), แฮชรหัสผ่านด้วย `bcryptjs` |
| Drag & drop | `@dnd-kit` |
| ตรวจข้อมูล | Zod 4 |
| ไฟล์แนบ | Vercel Blob |
| ทดสอบ | Node.js test runner ผ่าน `tsx` |

> **Prisma กับ Neon เป็นคนละอย่าง** — Neon คือเซิร์ฟเวอร์ที่เก็บข้อมูลจริง ส่วน Prisma คือไลบรารีในโค้ด
> ที่ช่วยเขียน query แบบ type-safe แทน SQL ดิบ

## ติดตั้งและรันในเครื่อง

**ต้องมี:** Node.js 20+ และฐานข้อมูล PostgreSQL 1 ตัว (สมัคร Neon ฟรีได้)

### 1. Clone และติดตั้ง

```bash
git clone <repository-url>
```

```bash
npm install
```

### 2. สร้างไฟล์ `.env` ที่รากโปรเจกต์

```env
# จำเป็น
DATABASE_URL="postgresql://..."      # connection string ของ PostgreSQL
AUTH_SECRET="..."                     # สร้างด้วย npx auth secret

# ไม่ใส่ก็รันได้
ADMIN_EMAILS="admin@kanban.dev"       # อีเมลแอดมิน คั่นด้วย comma (เป็นแอดมินเสมอ)
BLOB_READ_WRITE_TOKEN="..."           # Vercel Blob สำหรับอัปโหลดไฟล์แนบ (ไม่ใส่ = แนบได้แค่ลิงก์)
```

- `AUTH_SECRET` สร้างได้ด้วย `npx auth secret` — เปลี่ยนค่านี้เมื่อไหร่ ผู้ใช้ทุกคนหลุดออกจากระบบ
- `ADMIN_EMAILS`: **สร้างบัญชีของอีเมลนั้นก่อนใส่ใน env** ไม่งั้นใครสมัครอีเมลนั้นก่อนจะได้เป็นแอดมิน
- ไฟล์ `.env` อยู่ใน `.gitignore` ห้าม commit

### 3. สร้างตารางในฐานข้อมูล

```bash
npx prisma migrate dev
```

```bash
npx prisma generate
```

### 4. ใส่ข้อมูลตัวอย่าง (ไม่บังคับ)

```bash
npx prisma db seed
```

จะได้บอร์ด "Study Plan" ที่ผูกกับรายวิชา "วิชาตัวอย่าง" (รหัส `KANBAN`) และบัญชีทดสอบ:

| บทบาท | อีเมล | รหัสผ่าน |
|---|---|---|
| นักศึกษา | `demo@kanban.dev` | `demopass123` |
| อาจารย์ | `teacher@kanban.dev` | `teacherpass123` |
| แอดมิน | `admin@kanban.dev` | `adminpass123` (ต้องอยู่ใน `ADMIN_EMAILS`) |

> ⚠️ รหัสพวกนี้อยู่ใน repo สาธารณะ **ห้ามรัน seed ใส่ฐานข้อมูลของเว็บจริง** หรือถ้ารันไปแล้ว
> ให้เปลี่ยนรหัสทุกบัญชีที่หน้า "บัญชีของฉัน" — รัน seed ซ้ำจะรีเซ็ตรหัสกลับเป็นค่าตัวอย่าง

### 5. รัน

```bash
npm run dev
```

เปิด [http://localhost:3000](http://localhost:3000)

## Deploy (Vercel)

1. ตั้ง Environment Variables บน Vercel: `DATABASE_URL`, `AUTH_SECRET`, `ADMIN_EMAILS`
   (และ `BLOB_READ_WRITE_TOKEN` ถ้าใช้อัปโหลดไฟล์)
2. ทุกครั้งที่มี migration ใหม่ ให้สั่งจากเครื่องตัวเองโดยให้ `DATABASE_URL` ชี้ไปฐานข้อมูลของเว็บจริง —
   build บน Vercel ไม่ได้ migrate ให้
   ```bash
   npx prisma migrate deploy
   ```
3. แก้ env แล้วต้อง redeploy ค่าใหม่ถึงจะมีผล
4. ฐานข้อมูลของเว็บจริงไม่ควรมีบัญชีจาก seed — สมัครบัญชีด้วยอีเมลจริง แล้วใส่อีเมลนั้นใน `ADMIN_EMAILS`

## โครงสร้างโปรเจกต์ (คร่าว ๆ)

```
auth.ts / auth.config.ts   # NextAuth (ส่วนที่แตะฐานข้อมูล / ส่วนที่ proxy ใช้ได้)

app/
  (app)/                   # หน้าที่ต้องล็อกอิน: dashboard, board/[id], calendar, search,
                           # review, courses, my-reviews, account, admin
  actions/                 # server actions ที่ใช้หลายหน้า (auth, บอร์ด)
  login/ signup/ invite/   # หน้าล็อกอิน / สมัคร / รับคำเชิญ
  suspended/               # หน้าแจ้งบัญชีถูกระงับ
  components/              # UI ที่ใช้ซ้ำ (ui/, app-shell/, dashboard/)
lib/                       # ตรรกะกลาง: สิทธิ์ (board-access, roles), แต้ม, วันที่, CSV ฯลฯ
prisma/                    # schema, migrations, seed
specs/                     # spec ของฟีเจอร์
```

## จุดออกแบบที่น่าสนใจ

- **กันสิทธิ์ 2 ชั้น** — `proxy.ts` เช็คแค่ว่ามี session แต่ทุก Server Action ตรวจสิทธิ์ซ้ำเองเสมอ
  เพราะหน้าจอถูกข้ามได้ ทดสอบด้วยการยิงคำขอตรงไปที่ server action โดยไม่ผ่านหน้าจอแล้วต้องถูกปฏิเสธ
- **เขตเวลา** — กำหนดส่งเก็บเป็นเที่ยงคืน UTC แต่ไทยเป็น UTC+7 เทียบตรง ๆ จะเพี้ยนข้ามวัน
  ทุกการเทียบวันจึงทำผ่าน "คีย์วันที่" ตามเวลาไทยในไฟล์เดียว (`lib/due.ts`)
- **กันฟาร์มแต้มที่ฐานข้อมูล** — unique constraint `(cardId, type)` แทนการเช็คในโค้ด
  กดพร้อมกันสองแท็บก็ได้แต้มครั้งเดียว
- **โบนัสทันกำหนดวัดจากเวลาที่ส่งตรวจ** ไม่ใช่เวลาที่อาจารย์กดอนุมัติ — อาจารย์ตรวจช้า นักศึกษาไม่เสียแต้ม
- **ไม่ส่งข้อมูลลับไปหน้าเว็บ** — ข้อมูลผู้ใช้ที่ส่งไป client เลือกเฉพาะฟิลด์ที่จำเป็น (ไม่มี hash รหัสผ่าน)
  และ CSV กัน formula injection (ชื่อการ์ดที่ขึ้นต้นด้วย `=` จะไม่กลายเป็นสูตรใน Excel)
